# Umamusume-parent-helper
Application to help optimize inheritance and spark chance for Umamusume, given veterans.json

Goal: 
Take a veterans.json file from the Hachimi plugin on Umamusume, and parse it to be able to find optimal veterans for best inheritance and spark chances for selected skills.

MVP scope:
The MVP will be able to read and parse a json, and also determine the most optimal veterans for a preset list of skills based on each style. 

Future plans:
Later, this project will allow for user-selected skills instead of presets, and be able to read directly from the game instead of relying on Hachimi.
